link: https://richard-siken-quote-generator.vercel.app/

This is a website created using next.js/react to provide the user with 
randomly generated quotes from Richard Siken's "Crush" and "War of the Foxes". 
A quote in this context is defined as a full sentence ended with a period. I wrote 
a script to parse pdfs of the poem and load them into .json file. These quotes can
be copied to the user's clipboard or be shared to tumblr and x directly from the website.
All quotes belong to and are intellectual property of Richard Siken.
